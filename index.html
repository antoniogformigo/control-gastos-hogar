Ligar a aplicação

Para utilizar a aplicação nos telemóveis autorizados, configure neste ficheiro o URL e a chave publicável do projeto Supabase antes de o publicar no GitHub Pages.

Não introduza aqui uma chave secreta nem uma chave service_role.
